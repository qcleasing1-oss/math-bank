# tools/authoring — เครื่องมือแต่งข้อสอบใหม่

เครื่องมือที่ใช้ผลิตชุด `data/sets/gen-chap-07-trigonometry.json` (104 ข้อ) และชุด `gen-chap-*` อื่น ๆ

## ทำไมเครื่องมือถึงต้องอยู่ใน repo

เดิมทั้งชุดอยู่แต่ในเครื่องชั่วคราวของ session ที่ทำงาน — **หายไปแล้ว 2 ครั้ง** และทุกครั้งต้องสร้างใหม่หมด
ตรงกับคติที่โครงการยึดมาตลอด: *"เอกสารที่ไม่อยู่ใน repo คือเอกสารที่ไม่มีใครอัปเดต"*

ผลที่ได้เพิ่มอีกอย่างคือ **แชทใหม่บูตได้ด้วย `git clone` ครั้งเดียว** ⇒ ทำงานทีละก้อนแล้วขึ้นแชทใหม่ได้
โดยไม่เสียเวลาสร้างเครื่องมือใหม่ (แชทที่ยาวเกินไปจะถูกบีบบทสนทนาซ้ำ ๆ จนตอบช้า)

## เริ่มใช้

```bash
bash tools/authoring/bootstrap.sh
```

สคริปต์นี้จะคัดลอก `k1/` `k2/` ไปไว้ที่ `/home/claude/` (พาธที่สคริปต์ทุกตัวตรึงไว้)
แล้วรันตัวสร้างทุกตัวใหม่ ปิดท้ายด้วยด่าน `regen_check.py`

## 🔑 ด่านหลักประกันของโฟลเดอร์นี้

ด่านนี้เปลี่ยนความซ้ำซ้อนนั้นให้เป็นสิ่งที่ตรวจได้ แทนที่จะเป็นหนี้ที่รอระเบิด

## กฎที่ห้ามพลาด (ย่อจากจดหมายครู)

- ⛔ **ห้ามเลือกระดับก่อนแล้วย้อนหาคะแนน** — `grade_b*.py` ต้องรันก่อนตัดสินระดับเสมอ
- ⛔ **ห้ามข้าม sympy** — ทุกข้อต้องผ่าน `verify_b*.py`
- 🔑 **กวาดด่านก่อนเขียนเฉลย** — แต่งเฉพาะโจทย์+คำตอบให้ครบก้อน → กวาดด่านทั้งก้อน → เขียนเฉลยเฉพาะข้อที่รอด
  (โพรบชั้นแรกทุกตัวต้อง `qonly=True` · ด่านที่ต้องใช้เฉลยจริงให้เป็นด่านชั้นสอง)
- ⛔ **ห้ามลบของเก่าที่เขียนไว้แล้ว** รวมถึงสคริปต์ `collide*.py` ที่ดูเหมือนใช้ครั้งเดียว — มันคือหลักฐานว่ากวาดชนไปแล้วจริง
- ⛔ ทุกข้อ `hasImage: false` ไม่มี `imageSpec`
- ตัวลวงทุกตัวต้องสืบกลับไปหา**จุดพลาดที่ตั้งชื่อได้** ⛔ ไม่ใช่เลขใกล้เคียงที่สุ่มมา
