ความต่างของ `fill` ที่ต้องจำ

| เรื่อง | `mc` | `fill` |
|---|---|---|
| `choices` | มี 4 ตัว | **ไม่มีสนามนี้เลย** |
| `correct` | int นับจาก 0 | **สตริงคำตอบ** |
| `accept` | ไม่มี | **มี** — ทุกรูปแบบที่ต้องนับว่าถูก |
| บรรทัด ✅ | ลงท้าย `→ <b>ตัวเลือก N</b>` | ⛔ **ห้ามมีคำว่า “ตัวเลือก” ทั้งไฟล์** |

## 1. โครงบังคับของ `explanation` (STANDARD v2 — ตัวตรวจ `check_k2.py` จับด้วย `startswith`)

เรียงตามนี้เท่านั้น สตริงว่าง `''` คั่นระหว่างบล็อก:

1. `'📚 <b>ความรู้พื้นฐานที่ต้องใช้</b>'` แล้วตามด้วยบรรทัด `• ...` **4–6 บรรทัด**
   — เขียนให้เด็กที่ไม่เก่งอ่านรู้เรื่อง อธิบายนิยาม/สูตร**พร้อมเหตุผล** ไม่ใช่แค่โยนสูตร
2. `''`
3. `'📐 <b>โจทย์กำหนด</b>'` + บรรทัด `• ...` สรุปสิ่งที่โจทย์ให้ (รวมบรรทัด “สังเกตหน้าตาก่อนลงมือ”)
4. `''`
5. `'🎯 <b>เป้าหมาย</b>'` + บรรทัด `• ...`
6. `''`
7. บรรทัดชื่อวิธี `'<b>【 คำอธิบายวิธีหนึ่งประโยค 】</b>'`
8. `''`
9. `'<b>ขั้นที่ 1 · ...</b>'` + บรรทัด `• ...` — **ต้องมีอย่างน้อย 3 ขั้น** คั่นแต่ละขั้นด้วย `''`
   ทุกขั้นต้องโชว์ **สูตร → ระบุตัวแปร → แทนค่า → ยุบ** ⛔ ห้ามลัด
10. `''`
11. `'✔ <b>ตรวจคำตอบ (วิธีอิสระ · <บอกสั้น ๆ ว่าใช้วิธีไหน>)</b>'` + บรรทัด `• ...`
    — ต้องเป็นวิธีที่**ไม่ใช่ทางเดินเดิม** (สเปกรายข้อบอกไว้แล้วว่าให้ใช้วิธีไหน)
12. `''`
13. `'✅ <b>คำตอบ</b> ...'` — **บรรทัดเดียวเท่านั้นในทั้งเฉลย**
    · `mc` ต้องลงท้ายด้วย `→ <b>ตัวเลือก N</b>` โดย `N = correct + 1`
    · `fill` ⛔ ห้ามมีคำว่า “ตัวเลือก” — จบประโยคด้วยค่าคำตอบพร้อมหน่วย
14. `''`
15. `'💡 <b>เทคนิค</b>'` + บรรทัด `• ...` 2–3 บรรทัด
16. `''`
17. `'⚠️ <b>จุดพลาด</b>'` + บรรทัด `• ...` **อย่างน้อย 3 บรรทัด** บรรทัดละหนึ่งเส้นทางพลาด
    บอกให้ชัดว่า “เด็กพลาดขั้นไหนถึงได้ค่านี้” และ**พิสูจน์ว่าค่านั้นผิดจริง**

### 🔷 กลุ่ม 7.1 — อัตราส่วนตรีโกณมิติ (q105–q112)

#### q105 — ง่าย · `fill` · `['7.1', '7.4']`
- **โจทย์:** กำหนดให้ $\theta$ เป็นมุมแหลม ซึ่ง $\sec\theta = \dfrac{41}{40}$ ค่าของ $\tan\theta$ เท่ากับเท่าใด
- **วิธี:** $\tan^2\theta = \sec^2\theta - 1 = \dfrac{1681}{1600} - 1 = \dfrac{81}{1600} \Rightarrow \tan\theta = \dfrac{9}{40}$ (บวก เพราะมุมแหลม)
- **correct:** `'9/40'` · **accept:** `['9/40', '0.225', '\\dfrac{9}{40}', '\\frac{9}{40}']`
- **ตรวจอิสระ:** สร้างสามเหลี่ยมมุมฉากด้าน $9$-$40$-$41$ แล้วยืนยันด้วยพีทาโกรัส $9^2+40^2=41^2$ จากนั้นอ่าน $\tan$ จากรูป
- **จุดพลาด (≥3):** (1) ตอบ $\dfrac{40}{9}$ เพราะกลับอัตราส่วน (นั่นคือ $\cot\theta$) · (2) ตอบ $\dfrac{1}{40}$ เพราะเอา $\sec^2-1$ แล้วลืมว่าตัวส่วนก็ต้องยกกำลังสอง · (3) ตอบ $\dfrac{9}{41}$ เพราะสับสนว่า $\tan$ ใช้ด้านตรงข้ามมุมฉาก (นั่นคือ $\sin\theta$)
- **rubric:** F1 C0 P1 T0 L0 = 2/15 ⇒ ง่าย · (P=1 บรรทัดฐาน q091/q095 · L=0 สัญลักษณ์ล้วน)
- **แม่พิมพ์:** G-SEC-VALUE-ACUTE / A-RATIO-VALUE / M-PYTHID-DIRECT
- **โพรบ:** `collide_b20.py` A1 + A1b — ทั้งคลังไม่มีข้อใดให้ค่า $\sec$ มาเปล่า ๆ พร้อมคำว่า “มุมแหลม” แล้วถามอัตราส่วนอีกตัว · ญาติใกล้สุดคือ `gen-chap-07-trigonometry-q007` ซึ่งให้ $\sec A - \tan A$ (ใช้กลไกสังยุค M-PYTHID-CONJ) ⇒ ตรงเฉพาะ A

#### q106 — ปานกลาง · `mc` · `['7.1']` · correct = 3
- **โจทย์:** รูปสามเหลี่ยมมุมฉากรูปหนึ่งมีด้านประกอบมุมฉากทั้งสองด้านยาวเป็นอัตราส่วน $8 : 15$ และมีเส้นรอบรูปยาว $120$ หน่วย ด้านที่ยาวที่สุดของรูปสามเหลี่ยมรูปนี้ยาวกี่หน่วย
- **วิธี:** ด้านเป็น $8k, 15k$ ⇒ ด้านตรงข้ามมุมฉาก $=\sqrt{(8k)^2+(15k)^2}=17k$ · $8k+15k+17k=40k=120 \Rightarrow k=3$ ⇒ ตอบ $17k = 51$
- **choices:** `['$17$', '$24$', '$45$', '$51$']`
- **ที่มาตัวลวง:** $17$ = หา $k$ ถูกแล้วแต่ลืมคูณ $k$ กลับเข้ากับ $17$ · $24$ = ตอบ $8k$ (ด้านที่สั้นที่สุด) · $45$ = ตอบ $15k$ (คิดว่าด้านประกอบมุมฉากที่ยาวกว่าคือด้านที่ยาวที่สุด ลืมว่าด้านตรงข้ามมุมฉากยาวที่สุดเสมอ)
- **ตรวจอิสระ:** แทน $24, 45, 51$ กลับเข้าพีทาโกรัส $24^2+45^2 = 576+2025 = 2601 = 51^2$ ✓ และบวกกันได้ $120$ พอดี
