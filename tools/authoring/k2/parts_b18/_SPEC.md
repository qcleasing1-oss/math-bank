## 1. โครงบังคับของ `explanation` (STANDARD v2 — ตัวตรวจ `check_k2.py` จับด้วย `startswith`)

เรียงตามนี้เท่านั้น สตริงว่าง `''` คั่นระหว่างบล็อก:

1. `'📚 <b>ความรู้พื้นฐานที่ต้องใช้</b>'` แล้วตามด้วยบรรทัด `• ...` **4–6 บรรทัด**
   — เขียนให้เด็กที่ไม่เก่งอ่านรู้เรื่อง อธิบายนิยาม/สูตรพร้อมเหตุผล ไม่ใช่แค่โยนสูตร

3. `'📐 <b>โจทย์กำหนด</b>'` + บรรทัด `• ...` สรุปสิ่งที่โจทย์ให้ (รวมบรรทัด “สังเกตหน้าตาก่อนลงมือ”)
4. `''`
5. `'🎯 <b>เป้าหมาย</b>'` + บรรทัด `• ...` บอกว่าจะหาอะไร
6. `''`
7. บรรทัดชื่อวิธี `'<b>【 คำอธิบายวิธีหนึ่งประโยค 】</b>'`
8. `''`
9. `'<b>ขั้นที่ 1 · ...</b>'` + บรรทัด `• ...` — **ต้องมีอย่างน้อย 3 ขั้น** (`ขั้นที่ 1`, `ขั้นที่ 2`, `ขั้นที่ 3` …)
   คั่นแต่ละขั้นด้วย `''` · ทุกขั้นต้องโชว์ **สูตร → ระบุตัวแปร → แทนค่า → ยุบ** ⛔ ห้ามลัด
10. `''`
11. `'✔ <b>ตรวจคำตอบ (วิธีอิสระ · <คำอธิบายสั้น ๆ ว่าใช้วิธีไหน>)</b>'` + บรรทัด `• ...`
    — ต้องเป็นวิธีที่**ไม่ใช่ทางเดินเดิม** เช่น แทนค่าตัวเลข · คิดย้อนกลับ · ใช้สูตรอีกรูป
12. `''`
13. `'✅ <b>คำตอบ</b> ... → <b>ตัวเลือก N</b>'` — **บรรทัดเดียวเท่านั้นในทั้งเฉลย** และต้อง
    **ลงท้ายด้วย** `→ <b>ตัวเลือก N</b>` โดย `N = correct + 1`
14. `''`
15. `'💡 <b>เทคนิค</b>'` + บรรทัด `• ...` 2–3 บรรทัด
16. `''`
17. `'⚠️ <b>จุดพลาด</b>'` + บรรทัด `• ...` **อย่างน้อย 3 บรรทัด** — บรรทัดละหนึ่งตัวลวง
    บอกให้ชัดว่า “เด็กพลาดขั้นไหนถึงได้ค่านี้” และ**พิสูจน์ว่าค่านั้นผิดจริง**

- **โพรบ:** `collide_b18d.py` — ไม่มีข้อใดในคลังใช้แม่พิมพ์ “ผลบวกสองเศษส่วนที่ตัวส่วนต่างกันแค่เครื่องหมาย”

### q101 — ปานกลาง · `['7.1', '7.2']` · correct = 0
- **โจทย์:** กำหนดให้ $\theta$ เป็นมุมในจตุภาคที่ 3 ซึ่งสอดคล้องกับสมการ $3\sin\theta = 2\cos\theta$ ค่าของ $\csc\theta$ เท่ากับข้อใด
- **วิธี:** $\tan\theta = \tfrac23$ ⇒ สามเหลี่ยมอ้างอิงด้าน 2, 3, $\sqrt{13}$ ⇒ จตุภาค 3 ให้ $\sin\theta = -\dfrac{2}{\sqrt{13}}$ ⇒ $\csc\theta = -\dfrac{\sqrt{13}}{2}$
- **choices (น้อย→มาก · ค่าประมาณ −1.803, −1.202, 1.5, 1.803):** `['$-\\dfrac{\\sqrt{13}}{2}$', '$-\\dfrac{\\sqrt{13}}{3}$', '$\\dfrac{3}{2}$', '$\\dfrac{\\sqrt{13}}{2}$']`
- **ที่มาตัวลวง:** $-\dfrac{\sqrt{13}}{3}$ = ตอบ $\sec\theta$ · $\dfrac32$ = ตอบ $\cot\theta$ (⭐ **เป็นบวก** เพราะลบหารลบ) · $\dfrac{\sqrt{13}}{2}$ = ลืมเครื่องหมายจตุภาค
- **rubric:** F2 C1 P2 T1 L0 = 6/15 ⇒ ปานกลาง
- **โพรบ:** `collide_b18b.py` — ไม่มีข้อใดในคลังให้สมการเชิงเส้นระหว่าง $\sin$ กับ $\cos$ แล้วถามค่าส่วนกลับ

### q102 — ปานกลาง · `['7.7']` · correct = 2
- **โจทย์:** จำนวนคำตอบทั้งหมดของสมการ $2\cos^2 x - 3\cos x + 1 = 0$ เมื่อ $0 \le x < 2\pi$ เท่ากับข้อใด
- **วิธี:** $(2\cos x - 1)(\cos x - 1) = 0$ ⇒ $\cos x = \tfrac12$ ให้ $x = \tfrac{\pi}{3}, \tfrac{5\pi}{3}$ · $\cos x = 1$ ให้ $x = 0$ (อยู่ในช่วง) ส่วน $x = 2\pi$ อยู่นอกช่วง ⇒ รวม **3** คำตอบ
- **choices:** `['$1$', '$2$', '$3$', '$4$']`
- **ที่มาตัวลวง:** $1$ = แก้ได้กิ่งเดียวและนับรากเดียว · $2$ = ทิ้งกิ่ง $\cos x = 1$ · $4$ = นับ $x = 2\pi$ ด้วยทั้งที่ช่วงเปิดปลายขวา
- **rubric:** F2 C1 P2 T1 L0 = 6/15 ⇒ ปานกลาง · จุดพลิกคือปลายปิดด้านซ้าย $x=0$ นับ แต่ $x=2\pi$ ไม่นับ
- **โพรบ:** `collide_b18g.py` — V1a (นับคำตอบ + $\cos^2$ · กวาดสองทิศ) ได้ 1 ข้อคือ `gen-chap-07-trigonometry-q079` ซึ่งเป็นกลไกคนละแบบ · V1b ได้ 2 ข้อ ไม่เกี่ยวข้อง

### q103 — ยาก · `['7.7', '7.5']` · correct = 0
- **โจทย์:** จำนวนจริงบวกที่น้อยที่สุดซึ่งสอดคล้องกับสมการ $\sin 3x = \cos 2x$ เท่ากับข้อใด
- **วิธี:** $\cos 2x = \sin\left(\dfrac{\pi}{2} - 2x\right)$ ⇒ วงศ์ที่ 1 : $3x = \dfrac{\pi}{2}-2x+2k\pi \Rightarrow x = \dfrac{\pi}{10}+\dfrac{2k\pi}{5}$ · วงศ์ที่ 2 : $3x = \pi - \left(\dfrac{\pi}{2}-2x\right)+2k\pi \Rightarrow x = \dfrac{\pi}{2}+2k\pi$ ⇒ ค่าบวกน้อยสุด $= \dfrac{\pi}{10}$
- **choices (น้อย→มาก):** `['$\\dfrac{\\pi}{10}$', '$\\dfrac{\\pi}{6}$', '$\\dfrac{\\pi}{5}$', '$\\dfrac{\\pi}{2}$']`
- **ที่มาตัวลวง:** $\dfrac{\pi}{6}$ = กระจายเป็นพหุนามใน $\sin x$ แล้วแยกตัวประกอบผิดจนได้ $\sin x = \tfrac12$ · $\dfrac{\pi}{5}$ = ใช้ผลบวกมุมเป็น $\pi$ แทน $\dfrac{\pi}{2}$ · $\dfrac{\pi}{2}$ = ⭐ **เป็นคำตอบจริงของสมการ แต่ไม่ใช่ตัวที่น้อยที่สุด** (มาจากการใช้วงศ์ที่สองวงศ์เดียว) — ตัวลวงที่อันตรายที่สุดเพราะแทนกลับแล้วสมการเป็นจริง **ต้องเขียนจุดพลาดข้อนี้ให้ชัดว่าอันตรายอย่างไร**
- **rubric:** F3 C2 P2 T2 L0 = 9/15 ⇒ ยาก · (ไม่ถึง 12 จึงไม่เข้ายากมาก ⛔ ไม่ดันมิติใด)
- **โพรบ:** `collide_b18e.py` — แม่พิมพ์ “$\sin$ ของพหุคูณ $=$ $\cos$ ของพหุคูณ แล้วถามคำตอบบวกน้อยสุด” ไม่ปรากฏในคลัง (แม่พิมพ์ที่อิ่มตัวคือ “ผลบวกคำตอบ” 77 ข้อ ซึ่งเลี่ยงแล้ว)
- 📌 ในขั้นตรวจคำตอบ ให้เดินวิธีอิสระด้วยการ**แทนค่าตัวเลข** ทั้ง $\dfrac{\pi}{10}$ (เป็นจริง) และตรวจว่าไม่มีคำตอบใดต่ำกว่านั้น โดยชี้ว่าค่าที่เล็กที่สุดของทั้งสองวงศ์คือ $\dfrac{\pi}{10}$ กับ $\dfrac{\pi}{2}$ ⇒ เทียบกันตรง ๆ

### q104 — ยากมาก · `['7.10', '7.9']` · correct = 3
- **โจทย์:** บอลลูนลูกหนึ่งลอยนิ่งอยู่เหนือจุด $O$ บนพื้นราบ มีเชือกสองเส้นผูกจากบอลลูนลงมายังหมุด $A$ และหมุด $B$ ซึ่งอยู่บนพื้นราบเดียวกัน เชือกที่ผูกกับหมุด $A$ ยาว 40 เมตร และทำมุม 30 องศากับพื้น ส่วนเชือกที่ผูกกับหมุด $B$ ทำมุม 45 องศากับพื้น ถ้ามุม $A\hat{O}B$ มีขนาด 150 องศา แล้วระยะระหว่างหมุด $A$ กับหมุด $B$ เท่ากับข้อใด (ตอบเป็นเมตร)
- **วิธี:** $h = 40\sin 30^{\circ} = 20$ · $OA = 40\cos 30^{\circ} = 20\sqrt3$ · $OB = \dfrac{h}{\tan 45^{\circ}} = 20$ · กฎของโคไซน์ $AB^2 = OA^2+OB^2-2(OA)(OB)\cos 150^{\circ} = 1200+400+1200 = 2800$ ⇒ $AB = 20\sqrt7$
- **choices (น้อย→มาก · ค่าประมาณ 20, 34.6, 40, 52.9):** `['$20$', '$20\\sqrt{3}$', '$40$', '$20\\sqrt{7}$']`
- **ที่มาตัวลวง:** $20$ = ใช้ $\cos 150^{\circ}$ เป็นบวก (ได้ $AB^2=400$) · $20\sqrt3$ = ตอบ $OA$ แทน $AB$ · $40$ = คิดว่ามุม $A\hat{O}B$ เป็นมุมฉาก
- **rubric:** F3 C2 P3 T2 L2 = 12/15 ⇒ ยากมาก (เข้าเงื่อนไข $tot \ge 12$ และ $T\ge2$ และ $F=3$) · L=2 เพราะเป็นสามมิติจริง (ระนาบตั้งสองใบ + ระนาบพื้นหนึ่งใบ) บรรทัดฐาน q073
- **โพรบ:** `collide_b18c.py` / `collide_b18d.py` — คำว่า “บอลลูน” ไม่ปรากฏในคลัง · แม่พิมพ์ที่อิ่มตัวคือ “มุมเงยสองจุดสังเกต” (8 ข้อ) ซึ่งข้อนี้ไม่ใช่ เพราะจุดยอดอยู่เหนือจุดที่สาม และมุมที่ให้เป็นมุมบนพื้นระหว่างสองหมุด
- 📌 ต้องอธิบายให้ชัดว่ามุม 150 องศาวัด**บนพื้นราบ**ที่จุด $O$ ไม่ใช่มุมระหว่างเชือกสองเส้น
