== เนื้อเต็ม gen-chap-07-trigonometry-q001 ==
   โจทย์: กำหนดให้ $A$, $B$ และ $C$ เป็นขนาดของมุมภายในทั้งสามมุมของรูปสามเหลี่ยมรูปหนึ่ง ซึ่ง $\tan A$, $\tan B$ และ $\tan C$ หาค่าได้ทุกตัว และ $\tan A : \tan B : \tan C = 1 : 2 : 3$ แล้วค่าของ $\sin^2 A + \sin^2 B + \sin^2 C$ เท่ากับข้อใดต่อไปนี้
   ตัวเลือก 1: $\dfrac{4}{5}$
   ตัวเลือก 2: $\dfrac{9}{5}$
   ตัวเลือก 3: $2$
   ตัวเลือก 4: $\dfrac{11}{5}$
   correct = 3

   ตัวเลือก 5: $\sec 2A + \sec 2B + \sec 2C = 4\sec A\sec B\sec C$
